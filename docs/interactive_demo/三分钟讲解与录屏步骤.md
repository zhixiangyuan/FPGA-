# 三个视频的讲解与录屏步骤

现在录制三个独立视频。详细输入和每次点击顺序以同目录《新手操作手册》为准。本文件说明取景、节奏与剪辑，不替代实际测试。

## 三个视频怎样安排

| 视频 | 启动文件 | 建议成片预算 | 最后保留的结果 |
|---|---|---:|---|
| 系统基础功能 | 视频1_系统基础功能演示.cmd | 100 秒 | 六项结果汇总及完成数量 |
| 系统性能 | 视频2_系统性能展示.cmd | 25 秒 | 完整交付、吞吐、时延、极差与同 VL 间隔 |
| 调度优化对照 | 视频3_调度优化对照演示.cmd | 30 秒 | 相同输入核对、两侧新实测值和变化百分比 |

三段建议合计 155 秒，剩余时间留给 PPT 项目介绍、实现证据和结论。预算是剪辑建议，不要求仿真在这些秒数内结束。若演示时间没有三分钟限制，可以完整保留更多操作。

## 录制前

1. 先按手册完整练习，确认每个按钮及对应结果。
2. 正式录制重新打开入口，使用新的独立运行目录。
3. 中文控制窗口是主要取景，ModelSim 波形作为补充；录制前调整位置和字体，确保结果可读。
4. 默认文本均为 I LOVE FPGA，数字参数已预填；不要把批量模式误称为本人逐字输入的消息。

## 视频一：基础功能

1. 01：发送默认消息；需要展示内容变化时，再改成 I LOVE FPGA 2026 发送。保留实际接收、长度和本次计数。
2. 02：核对默认 32 帧、4 VL、64 字节、33000 周期，确认批量，保留每个通道各八帧及同 VL 间隔。
3. 03：按手册逐项切换双网、仅 A、仅 B、A 错误、双断、恢复。保留本人点击应用和发送，展示本次交付与错误计数。双断无交付是正确负例。
4. 04：先正常，依次 FCS/IP/UDP 错误，再正确 SN2，最后异常 SN9。保留错误类型、序号及对应拒收增量。
5. 05：先 GET 初始值，再 SET I LOVE FPGA，再 GET 实际读回值，不能只展示 SET 或输入框。
6. 06：确认默认时间参数并发送响应，展示同步 0→1、实际 offset 和 delay。
7. 最后切到结果汇总。只有实际完成全部子测试，才能展示基础功能完成 6/6；不能用自动实施自检或预填结果代替。

切页由整合窗口管理独立仿真。编译和等待可裁剪，但必须保留本人关键选择、点击及真实结果；不要在仿真运行中切页。

## 视频二：性能

使用新的独立入口，保留默认 64 帧、16 VL、1471 字节、8100 周期。拍到参数确认，随后展示全部交付和本次实际性能。最大观测时延不是全局最坏时延；时延极差没有明确数值判据时只显示实测值。不能把两组不同输入负载的差异解释成算法优化收益。

## 视频三：优化对照

拍到本人确认固定管理积压压力条件，以及优化前后两套新仿真结果。必须保留实际输入一致性核对。两侧只改变仲裁器，使用已验证配套历史生产 RTL 快照；不扩大为当前全部 RTL 或任意负载的固定提升。收益以本次新测量为准。

## 嵌入 PPT

把三个本人实际操作的视频插入对应页面。字幕写明 RTL 仿真和实际负载条件。工程与综合报告证据可以作为 PPT 静态页面，不必单独录原 09。完整播放计时，确认画面能看清实际数值，视频没有重复或缺失。

原 01～09 入口保留在「单项测试入口」用于独立排查或重录。历史报告、自动实施验证和人工录屏分别标明；不把旧回归日志、动画或预期值冒充这次实际结果。
